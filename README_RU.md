# Зеркало CarPlay для MGU Store

Это адаптация проекта Isaak для установки через источник в Store.
Карта копируется с центрального экрана; отдельного второго потока CarPlay здесь нет.

## Добавление

В репозитории GitHub файл `mgu-repo.json` должен лежать в корне, рядом с папками `apps`, `tools` и `LICENSES`.
В Store: Settings → Add source → указать `владелец/репозиторий` → выбрать Branch main.
Затем установить **CarPlay Map Mirror**. Необходимые компоненты Store установит как зависимости.
Если Store просит перезапуск, выполнить его через Settings → Restart head unit.

В настройках приборки выбрать карту в центральной области.
Открыть **CarPlay Map Mirror** → **Enable map mirror**, затем CarPlay Dashboard: карта слева, виджеты справа.
После каждого запуска головного устройства зеркало выключено; оно включается кнопкой в приложении.
**Disable map mirror** выключает вывод. Закрытие приложения с кнопкой зеркало не выключает.

## Ограничения

Исходный автор проверял зеркало на G20. На X3 G01 версия 0.1.0 показала карту, но с неправильным распознаванием и масштабом. В 0.1.2 переработаны эти механизмы; отображение обновлённой версии ещё нужно проверить на машине. Эмулятор BMW не использовался.
Локально проверены распознавание источника настоящим кодом Store, упаковка двух компонентов,
контрольные суммы, сборка приложения с синтетическим SDK и логика включения/выключения.
Это не подтверждает работу реального видеозахвата и вывода на приборку конкретной машины.

Расчётная поверхность центрального экрана — 1920×720; карта приборки — 1088×480.
Версия 0.1.2 работает только с Dashboard. Распознавание использует значок сетки 3×3 внизу боковой панели и область карты, независимо от красной/серой темы карточек. При открытии Spotify, полноэкранной карты или меню приложений зеркало скрывается; при возврате Dashboard включается само, пока пользователь не нажал Disable. Неизвестный вид экрана не выводится. Ручной обход проверки удалён.

В 0.1.3 новый основной режим — **View: Fit cluster**. Весь выбранный участок карты вписывается с сохранением пропорций в прямоугольник 504×368 со смещением 286,72 внутри слоя 1088×480. Такой прямоугольник использует исходный патч CarPlay как безопасную область интерфейса. Остальная часть видеослоя чёрная: карта становится компактнее, а её края не уходят за шкалы из-за масштабирования на весь слой. Реальное перекрытие штатными виджетами ещё нужно подтвердить на машине.

Кнопка View переключает Fit cluster / Balanced / More map / Larger details. Старые режимы заполняют весь видеослой и могут закрываться шкалами. Настройка из 0.1.2 при обновлении заменяется на Fit cluster; дальнейший выбор сохраняется. Штатные приборы и музыкальный виджет BMW приложение не убирает.

Частота — до 6 кадров/с; захваты идут последовательно без очереди. Чужой экран проверяется повторно с целевым циклом 200 мс; выход в BMW и Disable скрывают зеркало сразу, в том числе во время незавершённого захвата. Нулевая задержка не гарантируется: время захвата и возврат слота карты зависят от машины. В диагностике доступны счётчик кадров, время захвата/обработки и состояние слота.
Не включать одновременно другое приложение, занимающее тот же слот карты.

## Удаление

В Store удалить сначала **CarPlay Map Mirror**, затем **CarPlay Map Mirror service**.
Кодировок, бинарника CarPlay и прошивки автомобиля приложение не меняет.

Исходники и авторы указаны в THIRD_PARTY.md. Ключи, VIN, токены и BMW SDK в пакет не включены.
